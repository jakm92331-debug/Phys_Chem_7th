# معايير المحتوى الدائمة — وحدات القياس والكتابة الرياضية

هذا المستند **معيار ملزم لكل درس حالي ومستقبلي** في منصّة «أفق العلوم»، ولكل شاشة ومختبر
وسؤال وتغذية راجعة. المعياران مفروضان آلياً في الاختبارات (راجع «كيف نحمي المعيار» في الأسفل)،
لذلك لا يمكن أن يتسرّب مخالف لهما إلى `main`.

---

## 1. وحدات القياس: الإنكليزية حصراً

كل وحدة قياس تظهر للطالب تُكتب بالرمز العلمي الإنكليزي القياسي (SI). **ممنوع** كتابة الوحدة
بالعربية (متر، ثانية، كيلوغرام…) أو باختصار عربي (`م/ث`، `كم/ساعة`، `°م`).

| الكمية | الرمز المعتمد | ممنوع |
|---|---|---|
| المسافة / الطول | `m` (و `cm`، `mm`، `km`) | متر، م |
| الزمن | `s` (و `min`، `h`) | ثانية، ث |
| السرعة | `m/s` | م/ث، متر/ثانية |
| السرعة (يومية) | `km/h` | كم/ساعة، كيلومتر/ساعة |
| التسارع | `m/s²` | م/ث² |
| الكتلة | `kg` (و `g`) | كجم، كيلوغرام |
| القوة | `N` | نيوتن |
| الطاقة / العمل | `J` | جول |
| الاستطاعة | `W` | واط |
| الضغط | `Pa` | باسكال |
| درجة الحرارة | `°C` | °م، درجة مئوية |

**المرجع الوحيد للرموز:** `src/lib/units.ts` (كائن `UNITS`). لا تُكتب الرموز يدوياً في المحتوى؛
استُخدم المكوّنات أو الثوابت حتى يمنع نظام الأنواع أي وحدة عربية:

```tsx
import { UNITS, formatQuantity } from '@/lib/units'
import { Measure } from '@/components/math/Math'

<Measure value={12} unit="metresPerSecond" />   // 12 m/s — في شجرة React
formatQuantity(20, UNITS.metre)                 // "20 m"  — داخل canvas أو نص عادي
```

`<Measure>` يفصل الرقم عن رمز الوحدة في صندوقين معزولين اتجاهياً (`unicode-bidi: isolate`)
وبلا التفاف سطري، فيبقى «12 m/s» سليماً داخل سطر عربي RTL.

يشمل المعيار: المحتوى التعليمي، المختبرات، القراءات الحيّة، تسميات المحاور في الرسوم،
الأسئلة والخيارات والشروح، البطاقات والملخّصات. **لا يمسّ المعيار لغة الشرح العربية نفسها.**

## 2. الكتابة الرياضية: KaTeX في كل مكان

أي تعبير رياضي — قانون، كسر، أُسّ، جذر، رمز، متغيّر، تعويض أو علاقة داخل الشرح أو مثال أو
سؤال أو مختبر — يُكتب LaTeX ويُعرض بـ **KaTeX**. لا يُعرض تعبير رياضي كنص عادي.

| السياق | الصيغة | مثال |
|---|---|---|
| تعبير داخل سطر عربي | `$…$` | `السرعة $5\ \mathrm{m/s}$ كبيرة` |
| معادلة مستقلة (كتلة) | `$$…$$` | `قانون السرعة $$v = \frac{d}{t}$$` |
| كتلة قانون في البيانات | حقل `tex` | `{ kind: 'formula', tex: '\\bar{v} = \\dfrac{d}{t}' }` |
| مكوّن مباشر | `<Tex>` / `<BlockMath>` | `<BlockMath tex="v = \frac{d}{t}" />` |

كل نص عربي في المنصة يُمرَّر عبر `<RichText>`، فتُعرض `$…$` تلقائياً بـ KaTeX ضمن الشرح
والأسئلة والخيارات والشروح والملخّصات، بلا أي عمل إضافى من كاتب المحتوى.

**الوحدات داخل الرياضيات** تُكتب بخط روماني قائم وبالرمز الإنكليزي: `5\ \mathrm{m/s}`.

### الدمج مع العربية RTL

- كل صندوق رياضي يحمل `dir="ltr"` و `unicode-bidi: isolate`، فلا ينعكس ترتيب الرموز
  ولا تنكسر علامة `=` أو شريطة الكسر داخل السطر العربي.
- الكتل الرياضية تمرّر أفقياً داخل صندوقها (`overflow-x: auto`) على الهاتف، فلا يتولّد
  تمرير أفقي للصفحة.
- مخرجات KaTeX تحمل MathML إلى جانب HTML، فتُقرأ المعادلة بقارئات الشاشة.

### الحقول التي تدعم الرياضيات (قائمة ملزمة)

**كل نص يصل إلى الطالب يمرّ عبر `RichText`** — لا يوجد أي مسار عرض يتجاوز KaTeX.
الجدول التالي يسرد الحقول حسب نوع العرض:

| السياق | الحقول | نمط العرض |
|---|---|---|
| `ContentBlocks` | `heading.text`، `text`، عناصر `list`، `steps[].text`، `formula.caption` | سطري + كتلي (`$$…$$` كتلة) |
| `ContentBlocks` | `definition.term`، `callout.title`، `steps[].title`، `formula.symbols[].meaning` | **سطري فقط** (`inlineOnly`) |
| `ContentBlocks` (مقارنة) | `compare.leftTitle` / `rightTitle` / `rows[].label` / `rows[].left` / `rows[].right` | **سطري فقط** |
| `QuestionSet` | `prompt`، `choices[]`، `explanation`، `misconception` (تحقّق + اختبار) | **سطري فقط** |
| `LessonShell` | `objectives[]`، عنوان/وصف اللوحة، مفردات `dt`/`dd`، عنوان/وصف زرّ المرحلة | مختلط (`inlineOnly` للزرّ ولمصطلح المفردات) |
| `MotionLab` | عنوان المهمة ووصفها، جملة العلاقة، عنوان الشكل البياني | **سطري فقط** |
| البطاقات والجداول | عناوين الوحدات والدروس، الوصف الفرعي، التمهيد، أوسمة الإنجاز وشروطها، صفوف الجرد | **سطري فقط** |
| `document.title` / `aria-label` | عناوين الصفحات، تسميات المقارنة | نص مجرّد عبر `mathToPlainText()` |

**لماذا `inlineOnly`؟** الحقول أعلاه تُعرض داخل عناصر سطرية (`<dt>`، `<strong>`، `<span>`،
`<th>`، `<button>`) أو داخل عنصر لا يسمح إلا بمحتوى سطري (`<p>`، `<h3>`). إقحام معادلة كتلية
(`$$…$$`) هناك يُنتج HTML غير صالح (`<div>` داخل `<span>`/`<p>`) ويكسر التصميم. لذلك يُجبر
`RichText` هناك على العرض السطري: نفس المعادلة، بلا صندوق كتلي.

```tsx
<RichText text={term} inlineOnly />   // مصطلح/عنوان/خلية: سطري دائماً
<RichText text={paragraph} />         // فقرة: $$…$$ تصبح كتلة واضحة
```

## 4. كاشف الوحدات العربية (`src/lib/content-standards.ts`)

الكاشف هو **المصدر الوحيد** لتعريف «ما يُعدّ وحدة عربية ممنوعة»، ويخدمه ملفّان:
`src/content-standards.test.ts` (يمسح كل ملفّات `src/`) واختبارات `src/lib/units.test.ts`.
أي استثناء أو قائمة سماح تُكتب **هنا فقط** (أو في الاختبارات) — لا في أي مكان آخر.

المنطق ليس بحثاً عن كلمة، بل **قواعد واعية بالسياق** على ثماني طبقات:

| القاعدة | تلتقط | مثال |
|---|---|---|
| `arabic-unit-symbol` | اختصار عربي ممنوع دائماً | `م/ث`، `كم/ساعة`، `°م` |
| `quantity-with-arabic-unit` | رقم + اسم وحدة (مفرد/مثنّى/جمع، بأرقام عربية أو هندية) | `100 متراً`، `٥ متر`، `20 ثانية`، `5 دقائق`، `3 كجم` |
| `unit-after-measure-cue` | كلمة قياس تتبعها الوحدة | `وحدة قياس الطول هي المتر`، `وحدتها المتر`، `وحدة القياس: المتر` |
| `unit-before-measure-cue` | الوحدة قبل كلمة القياس | `المتر وحدة قياس الطول`، `المتر وحدة الطول` |
| `time-unit-after-measure-cue` | `الزمن`/`الوقت` + وحدة زمن (بغير أل التعريف، لتجنّب «الوحدة الثانية») | `الزمن بالثانية`، `المدة بالدقيقة` |
| `unit-with-attached-preposition` | الباء = «بوحدة» | `المسافة تُقاس بالمتر`، `بالكيلومتر في الساعة` |
| `unit-word-in-parentheses` | اسم وحدة بين قوسين (تسمية عمود/جدول) | `المسافة (متر)`، `الزمن (ثانية)` |
| `lone-arabic-unit-letter` | حرف وحدة مفرد بعد رقم أو وسم أو قوس | `12 م`، `</span> م`، `20 ث`، `(م)` |

**ضبط الحدود:** لا تُستخدم `\b` (لا تعمل مع العربية) بل `WORD_START` = `(?<![\p{L}\p{N}_])`
و`WORD_END` = `(?![\p{L}\p{N}_])`، مع `TAIL` يسمح بالتنوين والحركات والتطويل، فتُلتقط
«متراً» و«سنتيمتراً»، ولا يُعتبر «كبيرة» أو «أثقال» أو «كتاب» وحدة.

**الكلمات التي يجب ألّا تُعتبر وحدات (حالات سالبة محفوظة في الاختبارات):**
«الوحدة الثانية»، «الدرس الأول»، «الدرجة الثانية»، «المرحلة الثانية»، «عقرب الساعة»،
«ملاحظة دقيقة»، «سيارة كبيرة»، «رفع أثقال»، «قصة حب وغرام»، «باسم الله»، «في الثانية الواحدة»،
«درجة الحرارة °C»، «5 m/s».

لإضافة صيغة جديدة: أضف الكلمة إلى المجموعة المناسبة في أعلى الملفّ، ثم نفّذ
`npm test src/lib/units.test.ts` للتأكّد من خلوّها من الإنذارات الكاذبة.
