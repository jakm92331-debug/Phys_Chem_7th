# معايير المحتوى الدائمة — وحدات القياس والكتابة الرياضية

هذا المستند **معيار ملزم لكل درس حالي ومستقبلي** في منصّة «أفق العلوم»، ولكل شاشة ومختبر
وسؤال وتغذية راجعة. المعياران مفروضان آلياً في الاختبارات (راجع «كيف نحمي المعيار» في الأسفل)،
لذلك لا يمكن أن يتسرّب مخالف لهما إلى `main`.

## 1. وحدات القياس: الإنكليزية حصراً

كل وحدة قياس تظهر للطالب تُكتب بالرمز العلمي الإنكليزي القياسي (SI). **ممنوع** كتابة الوحدة
بالعربية (متر، ثانية، كيلوغرام…) أو باختصار عربي (`م/ث`، `كم/ساعة`، `°م`).

| الكمية | الرمز المعتمد | ممنوع |
|---|---|---|
| المسافة / الطول | `m` (و `cm`، `mm`، `km`) | متر، م |
| الزمن | `s` (و `min`، `h`) | ثانية، ث |
| السرعة | `m/s` | م/ث، متر/ثانية |
| السرعة (يومية) | `km/h` | كم/ساعة، كيلومتر/ساعة |
| التسارع | `m/s²` | م/ث² |
| الكتلة | `kg` (و `g`) | كجم، كيلوغرام |
| القوة | `N` | نيوتن |
| الطاقة / العمل | `J` | جول |
| الاستطاعة | `W` | واط |
| الضغط | `Pa` | باسكال |
| درجة الحرارة | `°C` | °م، درجة مئوية |

**المرجع الوحيد للرموز:** `src/lib/units.ts` (كائن `UNITS`). لا تُكتب الرموز يدوياً في المحتوى؛
استُخدم المكوّنات أو الثوابت حتى يمنع نظام الأنواع أي وحدة عربية:

```tsx
import { UNITS, formatQuantity } from '@/lib/units'
import { Measure } from '@/components/math/Math'

<Measure value={12} unit="metresPerSecond" />   // 12 m/s — في شجرة React
formatQuantity(20, UNITS.metre)                 // "20 m"  — داخل canvas أو نص عادي
```

`<Measure>` يفصل الرقم عن رمز الوحدة في صندوقين معزولين اتجاهياً (`unicode-bidi: isolate`)
وبلا التفاف سطري، فيبقى «12 m/s» سليماً داخل سطر عربي RTL.

يشمل المعيار: المحتوى التعليمي، المختبرات، القراءات الحيّة، تسميات المحاور في الرسوم،
الأسئلة والخيارات والشروح، البطاقات والملخّصات. **لا يمسّ المعيار لغة الشرح العربية نفسها.**

## 2. الكتابة الرياضية: KaTeX في كل مكان

أي تعبير رياضي — قانون، كسر، أُسّ، جذر، رمز، متغيّر، تعويض أو علاقة داخل الشرح أو مثال أو
سؤال أو مختبر — يُكتب LaTeX ويُعرض بـ **KaTeX**. لا يُعرض تعبير رياضي كنص عادي.

| السياق | الصيغة | مثال |
|---|---|---|
| تعبير داخل سطر عربي | `$…$` | `السرعة $5\ \mathrm{m/s}$ كبيرة` |
| معادلة مستقلة (كتلة) | `$$…$$` | `قانون السرعة $$v = \frac{d}{t}$$` |
| كتلة قانون في البيانات | حقل `tex` | `{ kind: 'formula', tex: '\\bar{v} = \\dfrac{d}{t}' }` |
| مكوّن مباشر | `<Tex>` / `<BlockMath>` | `<BlockMath tex="v = \frac{d}{t}" />` |

كل نص عربي في المنصة يُمرَّر عبر `<RichText>`، فتُعرض `$…$` تلقائياً بـ KaTeX ضمن الشرح
والأسئلة والخيارات والشروح والملخّصات، بلا أي عمل إضافى من كاتب المحتوى.

**الوحدات داخل الرياضيات** تُكتب بخط روماني قائم وبالرمز الإنكليزي: `5\ \mathrm{m/s}`.

### الدمج مع العربية RTL

- كل صندوق رياضي يحمل `dir="ltr"` و `unicode-bidi: isolate`، فلا ينعكس ترتيب الرموز
  ولا تنكسر علامة `=` أو شريطة الكسر داخل السطر العربي.
- الكتل الرياضية تمرّر أفقياً داخل صندوقها (`overflow-x: auto`) على الهاتف، فلا يتولّد
  تمرير أفقي للصفحة.
- مخرجات KaTeX تحمل MathML إلى جانب HTML، فتُقرأ المعادلة بقارئات الشاشة.

### الحقول التي تدعم الرياضيات

`RichText` مطبَّق على: نصوص الشرح والتعاريف والتنبيهات وعناصر القوائم والخطوات وخلايا
المقارنة وعناوين الأقسام، وعلى أسئلة التحقق والاختبار (السؤال، الخيارات، الشرح، تنبيه
الفهم الخاطئ)، وعلى أهداف الدرس وملخّصه ومفرداته وتحدّيات التطبيق ووصف مهام المختبر.
